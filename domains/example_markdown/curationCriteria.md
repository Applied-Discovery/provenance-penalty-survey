# Curation criteria: example_markdown domain

The eight artifacts in this domain are placeholder question-and-answer pairs
written for this repository, in the shape of the legal domain's pool (a
`## Question` and an `## Answer` section in Markdown). The human placeholders
carry a list, a heading inside the answer, a quote, bold and italics (and
the AI placeholder of pair 1 a numbered list, so every session shows one) so the
Markdown rendering can be checked on the dev server. They were not curated
against any selection criteria, are not drawn from a real human or AI
population, and must never be treated as, or included in, a study pool.

A real domain replaces this entire file with the frozen curation criteria
for its actual artifact pool, and that file — together with the domain's
`domainManifest.json` and artifacts — is uploaded to OSF and frozen before
data collection begins, per `02_design/BENCHMARK.md`.
