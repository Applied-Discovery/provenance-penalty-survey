# Curation criteria: example opinion domain

The eight artifacts in this domain are placeholder arguments written for this
repository, one human-labelled and one AI-labelled argument per motion. They
exist only to exercise the per-artifact demographic question (`per_artifact`
with `{{title}}`), which asks how much the participant agrees with each
argument they rated. They were not curated against any selection criteria and
must never be treated as, or included in, a study pool.
