# Curation criteria: example domain

The four artifacts in this domain (`artifacts/h0.txt`, `h1.txt`, `a0.txt`,
`a1.txt`) are placeholder text written for this repository. They exist only
to exercise the build, validation, and rendering pipeline (Task 13 and its
automated walkthrough in Task 15). They were not curated against any
selection criteria, are not drawn from a real human or AI population, and
must never be treated as, or included in, a study pool.

A real domain replaces this entire file with the frozen curation criteria
for its actual artifact pool (selection rules, source, date range, exclusion
rules, etc.), and that file — together with the domain's `domainManifest.json`
and artifacts — is uploaded to OSF and frozen before data collection begins,
per `02_design/BENCHMARK.md`.
